# Controluce

Sito statico per richiedere litofanie in cornice stampate in 3D, senza pagamento online.

- Anteprima 3D della litofania (three.js) con simulazione della luce trasmessa
- Editor di inquadratura con proporzioni 3:4, 1:1, 2:3 e orientamento verticale/orizzontale
- Richiesta d'ordine inviata via WhatsApp o email
- Lingue: italiano, inglese, francese, spagnolo (`i18n.js`)

## Configurazione

In cima ad `app.js`, nell'oggetto `CONFIG`: numero WhatsApp, email, misure e prezzi.

## Avvio locale

Apri `index.html` nel browser. Nessuna build richiesta.
